CensorCut

Reads <movie>.censorcut-edl.json beside each movie and reports its cuts as media segments so clients skip them. The film itself is never modified.

On the server adds a "Censored" version whose stream is already cut, so it works on every client and cannot be bypassed. It always transcodes, so it costs CPU while playing.
In the client reports the cuts as skippable segments. It allows direct play, but a client without automatic skipping plays the film uncut — it fails open.
Server mode only. Playback has to resume on a keyframe, so each cut ends at the first keyframe after it — never before, which would replay the scene being removed. This bounds how far ahead to look; if no keyframe is found within it, no censored version is offered rather than an unsafe one.
Jellyfin has no "censored" segment type, so cuts borrow one. Commercial is usually the type clients auto-skip most reliably.
Which profile to apply, for example age-7. Leave empty to use the one named by each edit list. If the id is not found, the strictest profile in the file is used rather than none.
How early each segment starts, so a slow client cannot show the opening moments of a cut. 0 uses the value stored in the edit list.
